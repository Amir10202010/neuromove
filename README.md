# NeuroMove

Проект объединяет веб-приложение для анализа движений по данным IMU-датчиков и прототип устройства на ESP32. Этот README — карта репозитория для команды.

## Папки проекта

| Путь | За что отвечает | С чего начать |
|---|---|---|
| [`website/`](website/README.md) | Веб-приложение: интерфейс, обработка данных и отчёты | [Инструкция по сайту](website/README.md) |
| [`firmware/`](firmware/README.md) | Код ESP32, настройки PlatformIO и проверки протокола | [Инструкция по прошивке](firmware/README.md) |
| [`hardware/models/enclosure/`](hardware/models/enclosure/) | CAD-исходники корпуса и актуальные файлы для 3D-печати | [Печать и сборка корпуса v3](hardware/models/enclosure/ПЕЧАТЬ-v3.md) |
| [`hardware/diagrams/`](hardware/diagrams/) | Схемы подключения и пайки, а также исходники схем | [Карта раздела hardware](hardware/README.md) |
| [`hardware/docs/`](hardware/docs/) | Сборка датчиков и проверка платы перед подключением | [Инструкция по сборке датчиков](hardware/docs/сборка-датчиков.md) |
| [`питч/`](питч/README.md) | Слайды питча и материалы для презентации | [Описание слайдов](питч/README.md) |

## С чего начать новому участнику

1. Посмотрите эту карту и выберите часть проекта, с которой работаете.
2. Откройте README выбранной папки: там описаны запуск, устройство кода и нужные проверки.
3. Для общего контекста проекта используйте документы в корне: [основа и план](основа-и-план.md), [софт](софт.md), [железо](железо.md) и [прототип](прототип.md).

Код и актуальные технические инструкции находятся в `website/`, `firmware/` и `hardware/`. Документы в корне и `website/docs/` содержат также плановые и исторические заметки; при работе ориентируйтесь на README и код соответствующей части проекта.

## Запустить веб-приложение

Нужен Node.js 20 или новее:

```bash
cd website
npm ci
npm run dev
```

Другие команды сайта, настройка PlatformIO и проверки прошивки описаны в README соответствующих папок.
