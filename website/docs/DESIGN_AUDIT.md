## Чего на странице нет и не будет

Логотипов клиентов, отзывов, числа пользователей, сертификатов, партнёрств и «точности на людях»:
их нет на самом деле. Пустые страницы «Безопасность», «Цены», «Компания» тоже не создаём — у
прототипа нет фактов для них. Где факта нет, страница говорит, что он будет проверен и как.
