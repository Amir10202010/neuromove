# Приёмка железа стенда: что проверить и что сохранить

Для Санжара: по шагам, от коробки с модулями до станка. У каждого шага — что сделать, что
должно получиться (записано **до** замера) и что сохранить. Сборка и прошивка подробно —
[`firmware/README.md`](../../../firmware/README.md); здесь — как понять, что всё работает,
и как это доказать.

Правило одно: **любой замер сохраняется, даже неудачный.** Плохой результат — это находка, а не мусор.
Файлы — в папку `stand-data/ГГГГ-ММ-ДД/` (заведите её при первом замере).

## Шаг 1. Модули из коробки

Для каждого GY-521 по отдельности, подключив его на место предплечья:

| Что | Как | Должно быть | Записать |
|---|---|---|---|
| Чип настоящий или копия | команда `info`, строка паспорта | WHO_AM_I `0x68`; `0x70`, `0x72`, `0x98` — копия: работать можно, но этот модуль первым под подозрение | значение WHO_AM_I |
| Отпечаток модуля | строка `# id_…` в паспорте | 8 знаков, не `none`; **у разных модулей разные** | отпечаток, подписать модуль маркером |
| Датчик лежит на столе чипом вверх | `info`, строка «ускорение … длина … g» | длина 0,89–1,11 g: крайние допуски даташита — ноль до ±80 мg по Z и масштаб ±3 % | три числа ускорения и длину |
| Гироскоп в покое | `info`, «поворот … °/с» | каждая ось не дальше ±20 °/с (ноль по даташиту); приложение вычтет его при калибровке | три числа |

Если у двух модулей одинаковый отпечаток — записать это: тогда защита от чужих поправок для них
не работает (`FINDINGS.md`, F11), и подпись маркером обязательна.

## Шаг 2. Проводка

| Что | Как | Должно быть |
|---|---|---|
| Питание | мультиметр на выводах VCC–GND каждого модуля, плата от USB | 3,2–3,4 В |
| Адреса | `scan` | шина 0: `0x68` (плечо, AD0 → GND) и `0x69` (предплечье, AD0 → 3V3); шина 1: `0x68` (грудь) |
| Кабель не рвёт связь | `info` до и после того, как кабель десять раз согнули и потрясли | «пропущено строк из-за сбоев чтения» не растёт |
| Подтяжки линий | ничего не делать: на плате GY-521 подтягивающие резисторы уже стоят; два модуля на шине — резисторы встают параллельно, для 100 кГц это нормально. Номинал на своих модулях посмотреть и записать | номинал |

## Шаг 3. Поток

Записать 60 секунд в приложении (подключить по USB, «Датчики», любой тест) и сохранить сырые
данные CSV.

| Что | Должно быть | Почему |
|---|---|---|
| Строк за 60 с | 6 000 ± 1 | 100 Гц по часам платы |
| Разрывов номеров | 0 | строка уходит, только если ответили все |
| `info` после записи: пропущено строк | 0 | |
| Сдвиг времени | нет: время отсчёта = номер / 100 | модель шины в host-тесте: 4,68 мс из 10 мс заняты, запас есть |

## Шаг 4. Калибровка каждого модуля

Команда `cal`, шесть положений (`firmware/README.md`, раздел 5). Потом **ещё раз** `cal` — проверить
повторяемость.

| Что | Должно быть | Записать |
|---|---|---|
| Прошивка приняла все шесть положений | да; «лежит не той гранью» или «двигался» — повторить положение | сколько раз повторяли |
| Ноль по осям | не дальше 0,1 g (819 единиц); прошивка сама отказывает дальше 0,2 g | строку `# cal_…` |
| Масштаб | 0,97–1,03 (9 700–10 300 в строке) — допуск даташита ±3 % | строку `# cal_…` |
| Повторяемость: разница двух калибровок | ноль — не больше 10 единиц (1,2 мg), масштаб — не больше 10 единиц (0,1 %) | обе строки |

Не прошёл повторяемость — модуль лежал неровно или стол качался: калибровать на твёрдом столе,
модуль в корпусе (у коробки ровные грани).

## Шаг 5. Станок: локоть, «плечо» вертикально

Как собрать и как мерить — `firmware/README.md`, раздел 6. Критерии записаны до замера:

| Угол на станке | 0° | 30° | 60° | 90° | 120° |
|---|---|---|---|---|---|
| Ошибка, круг 1 | | | | | |
| Ошибка, круг 2 | | | | | |
| Ошибка, круг 3 | | | | | |

**Прошли**, если ошибка не больше 3° на каждом угле в каждом круге (`прототип.md`, раздел 7)
и средняя по всем — не больше 5° (SMART v2). Что ждать по модели: средняя 0,05–1,0° на восьми
случайных датчиках (`EXPERIMENTS.md`, C1-elbow).

## Шаг 6. Станок: «плечо» отклонено назад — проверка находки F1

Новая проверка, её не было в плане. На модели старая формула локтя ошибалась на −21° при плече,
отклонённом назад на 10°; новая — на 1–1,5° (`FINDINGS.md`, F1). Станок — единственный способ
проверить это на железе без людей.

**Как.** Неподвижную рейку («плечо») поставить не вертикально, а с наклоном **назад на 10°**
(клин или подставка, угол — по транспортиру или угломеру телефона). Калибровка — как обычно,
но в позе калибровки обе рейки висят вертикально; потом «плечо» отклонить назад на 10°
и закрепить, и уже тогда выставлять углы «предплечья» относительно «плеча»: 30°, 60°, 90°, 120°.
Три круга. Затем то же с наклоном **в сторону на 10°**.

| | 30° | 60° | 90° | 120° |
|---|---|---|---|---|
| Назад 10°, средняя ошибка | | | | |
| В сторону 10°, средняя ошибка | | | | |

**Прошли**, если ошибка не больше 5° на каждом угле. Что ждать по модели: худшая ошибка объёма 1,0–1,5°
(C13-elbow-180-10 и C13-elbow-90-10).
Если не прошли — это важнее всего остального: значит, ось Z датчика плеча не совпадает
с осью «локтя» станка (проверить, что модуль на рейке плеча стоит стрелкой X вдоль рейки
и крышкой наружу, а петля станка перпендикулярна рейкам).

## Шаг 7. Корпус

| Что | Как | Должно быть |
|---|---|---|
| Плата входит | вложить GY-521 | без усилия; между упорами и стенками ходит не больше 1 мм (зазор 0,4 мм на сторону плюс разброс размеров плат) |
| Крышка держится | надеть и потрясти | не слетает; если слетает — проверить параметры защёлки `Snap` в `hardware/models/enclosure/korpus_v2.py` и записать новую подгонку |
| Ремешок | продеть | проходит без складок; ширину прорези — по ответу специалиста (`интервью-крепление.md`) |
| Края | провести пальцем | нет острых заусенцев; снять надфилем |
| Протирка | спиртовая салфетка, 10 раз | PETG не мутнеет и не липнет; PLA — записать, как повёл себя |

## Шаг 8. Если что-то не так

| Признак | Сначала проверить | Потом |
|---|---|---|
| «нет ни одного датчика» | питание 3V3 и GND мультиметром | SDA/SCL не перепутаны; выводы купленной платы — 21/22 и 32/33, у S3 — 8/9 и 4/5 |
| Один датчик не виден в `scan` | его провода и пайку | AD0: у предплечья — на 3V3 |
| Датчик то есть, то нет («перезапускаю шину») | кабель при движении — тот же тест с потряхиванием | короче кабель, пайка, стяжка у корпуса |
| Приложение: «нет данных от датчика» посреди теста | `info`: убран ли он из потока | тот же кабель; модуль заменить |
| Каракули в мониторе | скорость монитора 460 800 (с 12 октября; на 921 600 плата с CH340C на маке даёт каракули) | у S3 — разъём COM, а не USB |
| Углы сползают за минуты | неподвижные 3 с калибровки позы | гироскоп модуля: `info` в покое |
| Угол врёт на постоянную величину | калибровка `cal` этого модуля | поправки не от другого модуля (предупреждение в паспорте) |
| Локоть врёт только при отклонённом «плече» | шаг 6: стрелка X и крышка модуля плеча | ось петли станка |
| Знак поворота предплечья наоборот | модуль предплечья надет крышкой к коже | крепление по `COORDINATES.md`, раздел 2 |

## Что сохранить — доказательства

| Что | Где |
|---|---|
| Текст `info` каждого модуля (шаг 1) | `stand-data/…/modules.txt` |
| Фото проводки сверху и сбоку | `stand-data/…/wiring-*.jpg` |
| Строки `# cal_…` обеих калибровок каждого модуля | `stand-data/…/calibration.txt` |
| Сырые данные 60 с потока (шаг 3) | CSV из приложения |
| Записи станка с отметками (шаги 5–6), все, включая неудачные | CSV из приложения, «Проверка точности» |
| Таблицы шагов 5–6 | этот файл или фото листа |

После первой полной приёмки — обновить `TRACEABILITY.md`: шаги 1–8 станут «проверено на железе».
