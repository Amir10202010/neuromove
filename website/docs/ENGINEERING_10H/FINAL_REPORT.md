## 4. Ответы на вопросы задания

**Насколько точен прибор?** На модели в покое средняя ошибка 0,05–1,1° на восьми датчиках
с ошибками по даташиту, в быстром движении средняя квадратичная около 3°. На железе и людях —
неизвестно.

**Что было опаснее всего?** Тихие ошибки: число без пометки. Локоть при плече назад (F1),
замёрзший датчик (F5, F18), нули в выгрузке (F6), калибровка с движением (F7).

**Что изменилось в алгоритме?** Только локоть (поворот в шарнире) и проверки вокруг угла.
Версия алгоритма `nm-core 0.2.0`. Остальные формулы не трогались: эксперименты показали,
что они в пределах критериев.

**Какие ограничения остались?** Перекрёстная чувствительность датчика (около 1°), переразгибание
локтя при висящем плече, вальгус с пронацией (−8…−10°), углы как дуга от позы калибровки
(теперь видно в отчёте).

**Что делать Санжару?** Купить детали и пройти `HARDWARE_ACCEPTANCE.md`, особенно шаг 6:
станок с «плечом», отклонённым на 10°.

**Что делать команде?** Решить, какой проект главный; показать демо реабилитологам; задать
новые вопросы интервью (`STARTUP.md`, разделы 7 и 9).

**Как повторить проверки?** `npm test`, `npm run e2e`, `npm run experiments`, `npm run mutate`
в `website`; `test/run.sh` в `firmware`.
