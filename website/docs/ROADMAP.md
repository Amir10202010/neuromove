# NeuroMove — план софта

Состояние на 1 октября 2026. Привязан к SMART v2 (`трекер.md`): к 11 декабря — прототип
одной руки прошёл проверку точности. Ограничение по времени: до школьного этапа олимпиады
(20 октября — 10 ноября) на софт — не больше двух вечеров в неделю (`README.md`, раздел 7).

Приоритеты: **P0** — без этого показ или данные под угрозой; **P1** — нужно к 11 декабря;
**P2** — после или если останется время.

| P | Что | Готово, когда | Зависит от |

| P0 | Проверка `SerialDevice` на стенде: потеря кабеля, перезагрузка платы, мусор в порту. Код к этому готов (1 октября): куски, мусор без перевода строки, перезагрузка и 16-битный seq покрыты юнит-тестами | обрыв → «Связь восстановлена» без потерь записанного | стенд |
| ✓ P1 | Запись с отметками эталона — **сделано 1 октября** в приложении: «Датчики» → «Проверка точности» → «Запись с датчиков» | на симуляторе — e2e; на стенде — первая же запись | стенд |
| ✓ P1 | Расчёт ошибки против станка и гониометра: средняя, максимальная, Бланд — Альтман — **сделано 1 октября** (`core/validation.ts`) | на записи станка из симулятора MAE 0.18–0.97°; на стенде — записи E1–E3 | стенд, `docs/PRODUCT_STRATEGY.md` |

| ◐ P1 | Калибровка каждого MPU-6050 в 6 положениях (заводской ноль ±50 мг) — коэффициенты в паспорте записи — **сделано 2 октября**: команда `cal` в прошивке, `# cal_<место>=…` в паспорте, приложение применяет в потоке, позе калибровки и проверке точности | ошибка наклона на столе меньше 1° — на плате | стенд |

## 6. Инженерный долг — по мере сил

| P | Что | Почему |
|---|---|---|
| P1 | CI в GitHub Actions: typecheck, lint, test, build на каждый push | сейчас проверки запускаются руками на двух компьютерах. **Нужно согласие Амирхана**: Actions тратят минуты аккаунта, на приватном репозитории квота ограничена |
| P2 | Разделить код лендинга и приложения (`React.lazy`) | сейчас один скрипт 766 КБ (227 КБ gzip). На этом компьютере лендинг рисуется за ~0.1 с, приложение открывается за ~1.4 с — из них ~1.2 с подготовка демо, а не загрузка, — так что выигрыш виден только на медленной сети |
| P2 | Проход с экранным диктором (VoiceOver, NVDA) | axe и свой тест 2.4.11 автоматические; диктор — только руками |
| P2 | Сквозные тесты в Safari и Firefox | показ планируется в Chrome; Web Serial в Safari нет |
| P2 | Обновление Vite 8, TypeScript 7, Vitest 5 | `npm outdated`; сейчас уязвимостей нет — обновлять отдельной задачей с прогоном e2e |
