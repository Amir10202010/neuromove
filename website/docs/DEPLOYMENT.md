# NeuroMove — запуск, сборка, выпуск, эксплуатация

Состояние на 1 октября 2026. Проверено на macOS, Node.js 24.14.1, npm 11.11.0, Chrome.

## 1. Что нужно

| Что | Зачем |
|---|---|
| Node.js 20 или новее, npm | сборка и тесты |
| Chrome или Edge на компьютере | настоящие датчики: Web Serial и Web Bluetooth есть только в браузерах на Chromium |
| Установленный Google Chrome | сквозные тесты Playwright идут в нём (`channel: 'chrome'`), браузеры Playwright не скачиваются |
| Интернет | только для `npm install` и `npm run docs:check` (Mermaid с jsDelivr). Само приложение работает без сети |

**Переменных окружения нет.** Секретов, ключей API и адресов серверов в приложении нет, поэтому нет
и `.env.example`. Во время сборки подставляются две константы: `__APP_VERSION__` (из `package.json`)
и `__BUILD_DATE__` (`vite.config.ts`).

## 2. Команды

```bash
cd website
npm install
```

| Команда | Что делает | Сколько идёт |
|---|---|---|
| `npm run dev` | сервер разработки, http://localhost:5173 | — |
| `npm run typecheck` | TypeScript strict, `tsc -b` | ~3 с |
| `npm run lint` | ESLint с правилами хуков React | ~4 с |
| `npm test` | юнит-тесты Vitest: алгоритмы, движок, контракт, архив, выгрузка | ~3 с |
| `npm run build` | сайт в `dist/` с политикой CSP | ~4 с |
| `npm run build:demo` | один файл `demo/NeuroMove.html`: всё внутри, CSP по хешу скрипта | ~4 с |
| `npm run preview` | раздать `dist/` локально | — |
| `npm run e2e` | сборка + сквозные тесты Playwright в Chrome: компьютер и Pixel 7 | ~1.5 мин |
| `npm run docs:check` | каждая диаграмма Mermaid из `docs/` рендерится | ~10 с |

В `.claude/launch.json` (корень репозитория) есть два запуска для превью: `neuromove` — сервер
разработки на порту 5174, `neuromove-build` — собранный сайт на порту 4174.

## 3. Три способа запуска

| Способ | Как | Сеть | Датчики | Для чего |
|---|---|---|---|---|
| А. Сайт | `npm run build`, папку `dist/` — на статический хостинг по https | нужна только для загрузки | Web Serial и Bluetooth доступны | показ по ссылке, работа в центре |
| Б. Один файл | `demo/NeuroMove.html` — двойной щелчок | не нужна | `navigator.serial` есть, с настоящим портом не проверено | показ в кабинете без Wi-Fi |
| В. Разработка | `npm run dev` | не нужна | доступны на localhost | стенд с ESP32 |

Адреса внутри — с решёткой (`#/patients/…`), поэтому сайт работает из подпапки и с диска без
настройки сервера.

## 4. Где разместить сайт — решает основатель

| Вариант | Цена | Ограничение |
|---|---|---|
| GitHub Pages из этого репозитория | платный план GitHub (Pro, Team): репозиторий `future` приватный, а Pages из приватного репозитория на бесплатном плане недоступен | **в репозитории — документы о поступлении и семье**: публиковать нужно только `dist/`, а не репозиторий |
| Отдельный публичный репозиторий только со сборкой `dist/` | бесплатно | это публикация: код сборки открыт всем; решает Амирхан |
| Netlify, бесплатный план | бесплатно | свой origin `*.netlify.app`; возраст по условиям — 13+ (`admissions/handbook/09-sources.md`) |

⚠️ **Один origin на все проекты.** Проектные сайты GitHub Pages живут по адресу
`<владелец>.github.io/<репозиторий>` — у всех проектов владельца один origin, а значит, общая
IndexedDB. Любая страница того же аккаунта может прочитать данные NeuroMove. Для демо это неважно,
для данных детей — нет: только отдельный origin (свой домен или отдельный аккаунт).
Подробнее — `docs/SECURITY_PRIVACY.md`, R3.

На своём хостинге добавить заголовки (через `<meta>` их задать нельзя):

```
Content-Security-Policy: default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'
Strict-Transport-Security: max-age=31536000
X-Content-Type-Options: nosniff
Referrer-Policy: no-referrer
Permissions-Policy: serial=(self), bluetooth=(self), camera=(), microphone=(), geolocation=()
```

## 5. Выпуск — по шагам

1. `git fetch origin && git status -sb`; при `behind` — `git pull --rebase` (правило `CLAUDE.md`).
2. `npm run typecheck && npm run lint && npm test` — всё зелёное.
3. `npm run e2e` — все тесты зелёные; при падении смотреть `e2e-report/index.html`.
4. `npm run docs:check`, если менялись диаграммы.
5. `npm run build:demo` и открыть `demo/NeuroMove.html` двойным щелчком: стартовая страница, знак,
   фото, «Попробовать демо».
6. Закоммитить и `demo/NeuroMove.html` — он лежит в репозитории намеренно (`.gitignore`).
7. Сайт: выложить `dist/` выбранным способом (раздел 4).

## 6. Обновление и откат

- **Приложение** — статические файлы: откат — выложить сборку прежнего коммита
  (`git checkout <коммит> -- app && npm run build`).
- **Данные** не на сервере, а в браузере каждого компьютера. Перед обновлением в центре —
  «Настройки» → «Скачать архив пространства» (JSON) на каждом компьютере.
- **Схема IndexedDB** — версия 1 (`data/db.ts`). Новая версия только добавляет хранилища и индексы.
  Старая сборка не откроет базу новой версии — откат данных только через архив JSON в чистом браузере.
- **Демо** перестраивается само, когда меняется `DEMO_SEED_VERSION` (`data/seed/demo.ts`); сеансы,
  записанные в демо, при этом пропадают. Пространство клиники не затрагивается.

## 7. Эксплуатация — что делать, если…

| Что видно | Почему | Что делать |
|---|---|---|
| «Загрузка…» дольше 5 с, потом «Хранилище недоступно: данные сохраняются только до закрытия вкладки» | браузер не дал IndexedDB (приватное окно, запрет для файла с диска) | открыть в обычном окне; для работы с пациентами — сайт по https |
| «Готовим демо-данные» ~1–2 с | первый запуск: демо-история симулируется тем же движком | ждать; дальше — из снимка мгновенно |
| «Не удалось открыть данные» | хранилище браузера не ответило при запуске | «Повторить»; сохранённые записи не удалены |
| «Сеанс был прерван» | вкладку закрыли посреди теста | «Продолжить сеанс» (переподключить датчики, повторить калибровку), «Сохранить собранное» или «Удалить» |
| «Связь с устройством потеряна» | обрыв связи | приложение пробует 5 раз; потом — «Подключить заново» или «Завершить» (собранное сохранится) |
| «Не удалось сохранить на диск» | хранилище переполнено или запрещено | «Скачать архив пространства», освободить место |
| Экран «Что-то пошло не так» | ошибка отрисовки экрана | данные не потеряны; «Перезагрузить страницу» или «На обзор» |

Телеметрии нет намеренно: приложение никуда не отправляет ни ошибки, ни статистику
(`connect-src 'none'`). Ошибку пользователь видит сам и сообщает команде.
