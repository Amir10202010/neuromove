# Hardware — железо и корпуса

Здесь собраны схемы и детали физического устройства NeuroMove:

- [`models/enclosure/`](models/enclosure/) — исходники CAD, текущие STL/STEP и готовые проекты Bambu Studio для печати корпуса v3.
- [`diagrams/`](diagrams/) — схемы подключения, пайки и сборки; рядом лежат исходники для их пересборки.
- [`docs/`](docs/) — пошаговая сборка датчиков и проверка платы до подключения.

За код, который запускается на ESP32, отвечает отдельная папка [`../firmware/`](../firmware/README.md). Общие сведения о датчиках и прототипе — в [`железо.md`](../железо.md) и [`прототип.md`](../прототип.md) в корне проекта.
